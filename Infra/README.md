# Infrastructure Projects

This folder serves as the container for different Terraform infrastructure management strategies.

## 📁 Sub-Projects

### 1. [State Manipulation](./statemanipulation/)
A dedicated lab for learning how to handle the Terraform state file manually.
- **Key Concepts**: `import`, `state mv`, `state rm`, and refactoring into modules.

### 2. [WorkSpace](./WorkSpace/)
Focuses on using Terraform Workspaces to manage multiple environments (e.g., Development, Production) using the same code base.
- **Key Concepts**: `terraform workspace new`, `select`, and environment-specific variables.

### 3. [Terraform](./terraform/)
General infrastructure deployments and resource group management.
- **Key Concepts**: Resource creation, provider configuration, and output variables.
